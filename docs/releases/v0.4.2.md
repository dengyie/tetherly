# Tetherly v0.4.2 — 键盘无法转发时指明原因

## 修复

- **光标到了 Windows，键盘却仍输入到 Mac**：原因是 macOS 安全输入（Secure Event Input）。只要有应用开着它，系统就不把键盘事件交给任何 event tap，但鼠标照常。开着它的可能是聚焦的密码框、终端的"安全键盘输入"，或没有正确释放它的应用。这个机制无法绕过，所以现在越界进入 Windows 时会做检测：
  - 日志里记一条 `keyboard not forwarded: macOS Secure Event Input is on`，带上占用者的 pid 和应用名；
  - 弹一条系统通知，指明是哪个应用。同一个占用者每分钟最多提醒一次。
- 处理办法：关闭该应用里的密码框，或退出、重启该应用。在终端里可以用 `ioreg -l -w 0 | grep SecureInput` 查看占用者的 pid。
